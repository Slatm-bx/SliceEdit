# SliceEdit
详细内容见SliceEdit软件文档

## 视频编辑软件

项目成员：柏翔 刘金林 王新凯

使用ffmpeg+qt实现

## 目标：

1.视频的多样播放：
可调节视频播放透明度，音量，视频播放窗口的方向，进行全屏操作等;

2.实现用于视频剪辑的ui：
视频剪辑列表，多视频预览条;

3.视频剪辑：
实现从单一视频中自由选取片段，合并且可导出为单一视频文件。

4.对多个视频进行剪辑：
能够一次性对多个视频剪切片段并组合，把组合好的视频保存到文件里面。

## 软件安装
软件依靠ffmpeg，必须先安装并加入环境变量，才能让软件正确运行
运行SliceEditInstaller根据界面引导进行安装，会自动添加快捷方式，默认安装位置为/opt/SliceEdit
